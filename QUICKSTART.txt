Si prefieres MySQL, crea la base de datos y configura .env con:

  DB_ENGINE=mysql
  MYSQL_HOST=localhost
  MYSQL_PORT=3306
  MYSQL_USER=root
  MYSQL_PASSWORD=
  MYSQL_DATABASE=inventario_general

Si vas a usar SQLite, no necesitas hacer nada adicional.


PASO 4: INICIALIZAR BASE DE DATOS

  $ python init_db.py

Esto creará las tablas y te preguntará si deseas cargar datos de prueba. No elimina la base de datos ni los registros existentes. La autenticación está desactivada por defecto, por lo que se omite la configuración de usuarios.
